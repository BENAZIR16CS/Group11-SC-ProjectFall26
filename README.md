Scholarship Management System

A web-based system for managing scholarships at University. It helps the Scholarship Committee advertise scholarships and review applications, and it helps students check eligibility, apply and track their application.

Project Overview

The system lets users:
- Log in with a role (student or scholarship committee member)
- View advertised scholarships
- Check eligibility (need based or merit based)
- Submit an application with documents
- Track the status of an application
- Verify applications, schedule and conduct online interviews, and generate results
- Generate and view feedback

Architecture

The system follows a three-tier architecture:

1. UI Layer:Student Interface and Scholarship Committee Interface
2. Application Layer:User Management, Scholarship Management, Application Management, Feedback Management
3. Data Services Layer:Database Access and File Storage
